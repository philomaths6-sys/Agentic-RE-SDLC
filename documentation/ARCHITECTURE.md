## 3. Human-in-the-Loop (HITL) Stage-Gate Workflow

Financial regulations mandate that automated systems cannot self-certify production execution. The architecture enforces two distinct stage gates:

```mermaid
sequenceDiagram
    autonumber
    actor User as Human Architect / Engineer
    participant UI as Streamlit Web UI
    participant Sup as Supervisor & Elicitation Agent
    participant RAG as Qdrant RAG Retriever
    participant Ext as 6-Pillar Extraction Agent
    participant Gate1 as Gate 1: Requirements Approval
    participant SDLC as SDLC Governance Agent
    participant Gate2 as Gate 2: SDLC Model Approval

    User->>UI: Enter project requirement or upload SRS (.docx/.pdf)
    UI->>Sup: Dispatch input with Zero-Trust safety filters
    Sup->>RAG: Retrieve statutory circulars & guidelines
    RAG-->>Ext: Grounding chunks (RBI, SEBI, NPCI)
    Ext->>UI: Generate 30+ modular requirements & SRS PDF
    Note over UI,Gate1: System Locks Execution Pending Human Review
    User->>Gate1: Inspect, Edit, or Verify 30+ Requirements
    Gate1->>SDLC: Unlock Step 2 (SDLC Prediction)
    SDLC->>UI: Predict recommended SDLC, rationale & trade-offs
    Note over UI,Gate2: Human Reviewer Can Accept or Override Model
    User->>Gate2: Approve Model or Select Manual Alternative
    Gate2->>UI: Render Phase Roadmap, WBS & Statutory Milestones
```

## 4. Hardware & Resource Budgeting (Edge-Optimized)

The entire multi-agent swarm is designed to execute locally on consumer/laptop GPUs (such as an NVIDIA RTX 3050 Laptop GPU with 6.0 GB VRAM):

- **Base Model**: `unsloth/Qwen2.5-3B-Instruct-bnb-4bit` (~2.05 GB VRAM).
- **LoRA Adapters**: Fine-tuned PEFT rank-16 adapters attached and dynamically swapped in shared memory (~30 MB).
- **Vector Search**: Qdrant vector database running in-memory or on-disk with fast HNSW cosine indexes (~150 MB RAM).
- **Relational DB**: Dockerized PostgreSQL 16 on port 5433 for multi-session persistence.
